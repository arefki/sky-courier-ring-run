# Sky Courier: Ring Run

A small original arcade flight game. Fly a prop courier plane through
12 rings over a procedural valley, then land back on the runway.

## Play

```sh
node serve.ts          # serves game/ at http://localhost:8080
```

Open http://localhost:8080 in desktop Chrome. No build step, no network
requests, no downloads — everything is generated by `game/game.js`.

## Controls

- **Arrow keys** — pitch and bank (turn)
- **W / S** — throttle up / down
- **Mouse** — steer by pointer position
- **P** — pause · **R** — restart · **M** — mute · **Enter / click** — start

## The flight

Take off from the runway, chase the gold ring (follow the guide dots and
the arrow). Each ring is +100 points and +5 seconds. Miss one and it turns
red — keep flying. After ring 12, turn around and land on the strip:
gentle touchdown, under 48 m/s, inside the runway. Three lives; terrain,
water and running out of time all end the flight.

## Files

- `game/` — the playable game as static files (`index.html`, `game.js`,
  `style.css`)
- `screenshots/` — 4 real renders of the game (cover: `1-ring-chase.jpg`)
- `main.ts` — the kit starter's hand-in program (copies `game/` and
  `screenshots/`, writes `dossier.json`)
- `vendor/makefun-game.ts` — the kit's library, unchanged
- `shots.json` — which `?shot=` view each screenshot was taken from

## Screenshots

The `?shot=` parameter stages a deterministic view for screenshots:
`?shot=title`, `?shot=ring`, `?shot=low`, `?shot=landing` (all with
`&seed=1`). `?selftest=1` runs the in-browser checks (terrain, projection,
a 90-second autopilot flight, one full render pass).
